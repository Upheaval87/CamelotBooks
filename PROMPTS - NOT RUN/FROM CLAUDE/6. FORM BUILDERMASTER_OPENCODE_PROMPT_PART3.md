## 2. SERVICES
============================================================
- FormDefinitionService (exists): forLoanType() → form+sections+fields ordered.
- FormCloneService::clone(ApplicationForm $src, string $name, string $slug):
  deep-copy sections + fields (new ids, preserve sort_order, options, conditions);
  return new form. Used by "Duplicate" (list, designer) and "New Form → duplicate".
- PermissionService: forRole(role)→collection; set(role,key,bool); reset(role)
  (re-seed from ROLE_DEFAULTS); groups() (categorised key list for UI).
- SystemSettingsService: get()/save(); apply() at boot sets interest method config;
  loan config values (pompo %, penalties, recovery) read from settings with
  fallback to config('loan.*')/.env.
