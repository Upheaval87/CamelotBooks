# System-Wide Typography & PDF Branding — Implementation Spec

**Objective:** Apply one typeface (Inter) with a fixed type scale to every web page,
and align every PDF document to the existing Invoice (INV-PROBE-001) branding.
This is a **visual-only** change. No routes, handlers, posting/period/lock logic,
filters, table data/columns, or button actions may change.

## 2 · Font Loading

- One family only: **Inter**, weights 400/500/600/700/800.
- Add preconnect + stylesheet once, in the base layout only:
```html
<link rel="preconnect" href="https://fonts.googleapis.com">
<link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap" rel="stylesheet">
```
- Define the stack once as a CSS variable and reference it everywhere — never
  hardcode `Inter` as a literal string in more than one place:
```css
--font-sans: "Inter","Segoe UI",system-ui,-apple-system,"Helvetica Neue",Arial,sans-serif;
```
- Remove/override any other `font-family` declarations so no second typeface
  survives anywhere in the app.
- **PDF note:** Google Fonts CDN links won't work inside DomPDF/TCPDF/mPDF —
  PDF templates need the Inter `.ttf`/`.otf` files registered locally with the
  PDF library. Confirm this during Phase 1 discovery, don't assume it "just works."

## 3 · Global Web Type Scale (single source of truth)

```css
body{font-family:var(--font-sans);font-size:14px;line-height:1.5;color:#374151;
  -webkit-font-smoothing:antialiased;text-rendering:optimizeLegibility}
h1{font-size:22px;font-weight:800;letter-spacing:-.01em;color:#0B2A2D}
h2{font-size:14px;font-weight:800;color:#0B2A2D}
h3{font-size:13px;font-weight:700;color:#0B2A2D}
label,thead th,.label{font-size:10.5px;font-weight:800;letter-spacing:.09em;
  text-transform:uppercase;color:#5f7476}
.small,.sub{font-size:12.5px;color:#5f7476}
.btn{font-family:var(--font-sans);font-size:13.5px;font-weight:600}
.btn-sm{font-size:12.5px}
.btn-xs{font-size:11.5px}
.num,td.num,.amount,.kpi .v,input[type=number]{font-variant-numeric:tabular-nums}
.kpi .v{font-size:20px;font-weight:800}
.kpi .l{font-size:10px;font-weight:800;letter-spacing:.08em;text-transform:uppercase}
.badge,.tchip{font-size:10px;font-weight:800;letter-spacing:.05em}
```

**Rules:**
- Hierarchy comes from weight/size only — never a second family.
- UPPERCASE + letter-spacing only for micro labels ≤10.5px.
- Weight 800 is reserved for titles and KPI values.
- `tabular-nums` on **every** numeric column, input, and KPI value.

> ⚠️ **Flag before applying:** this scale sets page titles (h1) at 22px. Double-check
> against whatever type scale is already live in the app — if page titles are
> currently a different size elsewhere in the system, decide which one wins and
> update this section before Phase 3 runs, so you're not overwriting an already-agreed
> scale with a conflicting one.

Apply this to every module: Dashboard, Sales, Purchasing, Inventory, Payroll,
Banking, Accounting (Journals/GL/TB/Fiscal/Periods/Cost Centres/Rates/
Classification), Financial Reports (IS/SFP/Cash Flow/A-R & A-P Aging),
Reversals, Chart of Accounts, Vendor/Customer centres, Settings, sidebar/rails.
Tables → 13px body + 10.5px uppercase headers. Forms → 13.5–14px inputs with
10.5px uppercase labels. Page heads 22px/800. Card heads 14px/800.

## 4 · PDF Typography

All PDF documents use the same Inter family (locally registered — see §2).

| Element | Size / Weight |
|---|---|
| Document title | 11px / 700, UPPERCASE, +.22em |
| Company name | 12px / 700 |
| Tagline | 7.5px |
| Meta labels | 7.5px UPPERCASE, +.1em |
| Meta values | 9px / 600 |
| Table header | 7.5px UPPERCASE |
| Table body | 9.5px |
| Subtotals | 600 |
| Grand totals | 700 |
| "Amount in words" | 8.5px italic |
| Footer | 8px |
| Signature labels | 7.5px UPPERCASE, +.1em |

`tabular-nums` on every figure. Negatives shown as grey parentheses — red
reserved for 90+ day overdue buckets only.

## 5 · PDF Branding (match Invoice INV-PROBE-001)

Every PDF gets the invoice's chrome, via **one shared header/footer partial**
reused by every document (not copy-pasted per template):

- **Header:** 30px deep-teal (`#0c3539`) rounded "C" tile + "CamelotBooks"
  (12px/700) + tagline "Enterprise Accounting & Advisory Services" (7.5px grey).
  Right side: document title UPPERCASE + letter-spaced, period line, 26×3px teal
  accent bar. 1px `#e5e7eb` rule below.
- **Meta block:** small teal uppercase labels + dark values (INVOICE NO./DATE/DUE
  for money documents; PERIOD/AS AT for statements). Financial statements get
  **no** boxed meta block — clean template.
- **Body:** hairline-ruled tables per §4; section ticks 2px teal; grand total
  gets a 2px ink rule.
- **Money documents only** (invoice/receipt/credit note): include an
  "Amount in words: … only." line and a "PAYMENT DETAILS" block (National Bank —
  Head Office · Account Name: CamelotBooks · Account Number · Branch).
- **Sign-off:** "Authorised By — Signature & Date" thin rule + "Prepared and
  issued by CamelotBooks."
- **Footer (identical on every PDF):** `www.camelotbooks.com · info@camelotbooks.com
  · +265 1 234 567` left, `Page 1 of 1` (or `Page x of y`) right, 1px `#e5e7eb`
  top rule, 8px `#9ca3af`.

## 6 · Accessibility / Quality Floor

- Body text ≥13px, micro labels ≥7.5px.
- Uppercase labels keep +.09–.12em tracking for legibility.
- Contrast: `#374151` on white ≥4.5:1; `#5f7476` for secondary text only.
- `tabular-nums` everywhere money/quantities need to align — never fake it with
  a monospace font.
- PDF text must stay selectable/searchable (real text, not rasterized images).
