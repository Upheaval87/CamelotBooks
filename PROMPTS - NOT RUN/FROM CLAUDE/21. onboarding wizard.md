PAYROLL — "ONBOARD A NEW EMPLOYEE" WIZARD — FULL IMPLEMENTATION SPEC (SELF-CONTAINED)
Includes the complete reference mockup HTML below (APPENDIX A). ONE FEATURE REBUILT: the
6-step employee onboarding wizard (Personal → Employment → Compensation → Deductions →
Banking → Review).

HARD GUARD — DO NOT CHANGE ANY FUNCTIONALITY: the existing employee-create handler,
employee model, department/branch/pension lookups and payroll integration keep current
behaviour. The wizard collects the same data and submits through the EXISTING handler.
This spec redesigns UI/UX + step flow only.

SYSTEM CONSTRAINTS: currency from system setting (never hard-coded); system live-search
results overlay above all content (z-index ≥9999); page renders as mocked (no rails).

==================== 0 · DISCOVERY ====================
0.1 Locate current add-employee template + create handler + field list + lookups
(departments, branches, employment types, pension schemes, payment methods).
0.2 List CURRENT controls/handlers (drives §9 audit).

==================== 1 · TOKENS / TYPOGRAPHY ====================
Inter (400–800). --deep-2:#0c3539; --sec:#128F8E; --ink:#0B2A2D; --muted:#5f7476;
--faint:#8aa5a7; --border:#dceaea; --line:#e2ecec; --green:#15803d; --red-2:#b91c1c;
body bg #eef4f4. Cards white 1px hairline 18px radius soft shadow; small-caps labels with
red * required / grey OPTIONAL tags.

==================== 2 · WIZARD STRUCTURE & STEPPER ====================
2.1 Header: breadcrumb Payroll › Employees › Add New; h1 "Onboard a new employee"; sub
"Six short steps with smart defaults."
2.2 Stepper (6 steps): Personal (Identity & contact) · Employment (Role & placement) ·
Compensation (Salary & benefits) · Deductions (Pension & allowances) · Banking (Payout
details) · Review (Confirm & submit), with connector bars between.
2.3 STATES (exact): UPCOMING = white circle, grey border, muted number + title, locked
(not clickable). CURRENT = white circle with teal ring (2px #128F8E + 4px glow), teal
number, dark title. COMPLETED = SOLID teal circle with white ✓, dark title, CLICKABLE to
revisit. Connector bar turns teal once the step before it is completed.
2.4 Progress line bottom-left: "Step {n} of 6 · {pct}% complete" (pct = round(n/6×100)).
2.5 Footer right: [← Back ghost] (hidden on step 1) + [Save & continue → sec]; on Review
the primary becomes [Submit & finish ✓ cta].

==================== 3 · STEP FIELDS (required *) ====================
S1 Personal: First Name*, Last Name*, Middle Name, Email*, Phone, Date of Birth, Gender,
National ID, Tax ID, Address (3-col grid; Address spans full row).
S2 Employment: Job Title*, Department*, Branch, Employment Type, Start Date*, Probation Ends.
S3 Compensation: Basic Salary*, Pay Frequency, Housing/Transport/Other Allowances (right-
aligned money inputs, system currency).
S4 Deductions: Pension Scheme, Employee Contribution %, Other Deductions.
S5 Banking: Payment Method, Bank Name, Account Number, Mobile Money Provider, Mobile Number.
S6 Review: read-only summary (Name; Job Title/Department; Basic Salary; Payment Method)
pulled live from entered data; success box "✓ Employee created — all 6 steps complete."

==================== 4 · BEHAVIOUR ====================
4.1 Save & continue validates the current step (client AND server): required fields non-
empty, email format; on fail show inline errors and DO NOT advance. 4.2 On success mark
step completed, advance, switch panel. 4.3 Back returns keeping data. 4.4 Clicking a
COMPLETED step jumps back to it; upcoming steps locked. 4.5 Panel switch on EVERY state
change (continue/back/step-click): hide all, show current with fade-in, focus first input,
scroll card into view. 4.6 Draft data persists in-page across navigation. 4.7 Submit on
Review posts to EXISTING create handler; on success show success box; no payroll recalc.

==================== 5 · NAMESPACING (collision-proof) ====================
All wizard selectors MUST be namespaced exactly as APPENDIX A: #wz-stepper, .wzstep, .wzc,
.wzt, .wzs, .wzbar, #wz-card, .wzpanel/.wz-on, state classes .wz-current/.wz-done. render()
removes then re-applies state classes each paint and runs once on load to guarantee
initial state (step 1 current, rest upcoming). DO NOT reuse generic .step/.bar/.panel
classes.

subtitles hidden ≤1000px; no page overflow at 1280/1024/768; text-size 90–125 no clipping;
no console/build errors.

  (function(){
    var steps=[].slice.call(document.querySelectorAll('#wz-stepper .wzstep'));
    var bars=[].slice.call(document.querySelectorAll('#wz-stepper .wzbar'));
    var panels=[].slice.call(document.querySelectorAll('#wz-card .wzpanel'));
    var card=document.getElementById('wz-card');
    var cur=0, done={};
    function showPanel(){
      panels.forEach(function(p,i){p.classList.toggle('wz-on',i===cur);});
      var first=panels[cur].querySelector('.in');
      if(first){first.focus({preventScroll:true});}
      card.scrollIntoView({behavior:'smooth',block:'start'});
    }
    function render(){
      steps.forEach(function(el,i){
        el.classList.remove('wz-done','wz-current');
        if(done[i]&&i!==cur){el.classList.add('wz-done');el.querySelector('.wzc').textContent='✓';}
        else{if(i===cur)el.classList.add('wz-current');el.querySelector('.wzc').textContent=String(i+1);}
      });
      bars.forEach(function(b,i){b.classList.toggle('wz-on',!!done[i]);});
      document.getElementById('prog').textContent='Step '+(cur+1)+' of 6 · '+Math.round(((cur+1)/6)*100)+'% complete';
      document.getElementById('back').style.display=cur>0?'':'none';
      var nx=document.getElementById('next');
      nx.textContent=cur===5?'Submit & finish ✓':'Save & continue →';
      nx.className='btn '+(cur===5?'btn-cta':'btn-sec');
      if(cur===5){
        var g=function(p,f){var el=panels[p].querySelectorAll('.in')[f];return el&&el.value?el.value:'—';};
        document.getElementById('r-name').textContent=g(0,0)+' '+g(0,1);
        document.getElementById('r-job').textContent=g(1,0)+' / '+g(1,1);
        document.getElementById('r-sal').textContent=g(2,0);
        document.getElementById('r-pay').textContent=g(4,0);
      }
      showPanel();
    }
    document.getElementById('next').addEventListener('click',function(){
      done[cur]=true;
      if(cur===5){document.getElementById('done').style.display='';render();return;}
      cur++;render();
    });
    document.getElementById('back').addEventListener('click',function(){if(cur>0){cur--;render();}});
    steps.forEach(function(el,i){el.addEventListener('click',function(){if(done[i]||i===cur){cur=i;render();}});});
    render();
  })();
</script>
